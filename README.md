# Java Swing Number & String Property Checker

## Overview

A Java Swing desktop application demonstrating
GUI programming, event handling, number-property
checking, and String class methods.

## Features

### Number Checker

- Prime
- Palindrome
- Perfect
- Armstrong
- Buzz
- Harshad

### String Method Tester

- equals()
- equalsIgnoreCase()
- startsWith()
- endsWith()
- contains()
- indexOf()

## Technologies

- Java
- Java Swing
- AWT
- Event Handling

## How to Run

Compile:

javac NumberChecker.java

Run:

java NumberChecker
